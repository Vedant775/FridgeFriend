# FridgeFriend – Food Expiry & Kitchen Stock Manager
A simple Python-based food expiry and kitchen stock management system that helps users manage food items, track expiry dates, update quantities, and receive low-stock warnings.

## About the Project
FridgeFriend is a simple Python-based mini project designed to help users manage food items stored in their kitchen. It allows users to maintain a record of food items, check expiry dates, update quantities, and receive low-stock warnings.

The main aim of this project is to reduce food wastage and make kitchen stock management easier.

## Features
- Add new food items.
- View all stored food items.
- Search for a particular food item.
- Update food quantities.
- Delete food items.
- Check expired food items.
- Find food items expiring within 3 days.
- Get low-stock warnings.
- Generate a kitchen stock report.
- Save records automatically in a JSON file.

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python main.py
```

5. Select an option from the menu to use the application.

## Data Storage
The project automatically saves food item details in a file named `food_items.json`. The saved records remain available even after closing and reopening the program.
